# NameColors

Changes the colours of player names in **Anvil Empires**.

**[Download NameColors.zip](../../../releases/latest/download/NameColors.zip)**
· [How to install](../README.md#installation)

Version 0.1.0, tested with the Anvil Empires playtest of November 2026 and
`UE4SS_v3.0.1-1181-g83330635`.

## What it does

Pick your own colour for the names of:

- **Pagans** (green in the game);
- **Ancients** (red);
- **Remnants** (blue);
- **Guild members** (yellow).

Choose the colours in the main menu: **Mods** button, then **Settings**
next to NameColors. It needs [ModManager](../ModManager/README.md). Each
colour has a palette and a **Default** button to go back to the game's
colour. Changes show in game within a second, and are kept for the next
game.

Your own name uses your faction's colour, as in the game: it cannot get a
colour of its own.

## What it does not do

It only changes what your own screen shows. Nothing is sent to the game's
server.

If a game update moves the colours, the mod notices it and leaves the
game's colours as they are until it is updated.
