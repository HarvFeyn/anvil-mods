# KeybindPlus

More shortcuts in the key settings of **Anvil Empires**.

**[Download KeybindPlus.zip](../../../releases/latest/download/KeybindPlus.zip)**
· [How to install](../README.md#installation)
· Author: [Feyn](https://github.com/HarvFeyn)

Version 0.1.0, tested with the Anvil Empires playtest of November 2026 and
`UE4SS_v3.0.1-1181-g83330635`.

## What it does

The game's **Keybinds** menu (Options → Keybinds) does not list every
shortcut. KeybindPlus adds the missing ones, so you can change them like
the others:

- **Item Slot 1** to **Item Slot 8**: the quick item slots, on `1` to `8`
  by default.

On a French **AZERTY** keyboard the number row types `&`, `é`, `"` ...
and the game does not see those keys as `1` to `8`: the item slots do
nothing. With KeybindPlus, open Options → Keybinds, click an Item Slot
entry and press the key you want (for example `&` for slot 1).

## Good to know

- The mod only adds the entries to the menu: the game's own menu code
  changes and saves the key, as for any other shortcut. The keys you pick
  stay even if you turn the mod off later (only the entries go away).
- **Reset Keybinds** puts the item slots back on `1` to `8` too.

## What it does not do

It does not press keys for you and sends nothing to the server: it only
lets you choose keys for actions the game already has.
